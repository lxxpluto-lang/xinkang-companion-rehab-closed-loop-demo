# 心康伴侣——训练执行与康复报告调研 Demo

> 本目录是独立的下一版原型，不覆盖历史 Demo，可通过本地 Git 回退。

本版本依据业务组会议最终结论收敛为：**医院正式处方开具完成后的训练执行、设备数据采集、康复报告与轻量随访系统**。

系统不在前端开具正式运动处方，也不替代 HIS/EMR。正式处方来源为院内 HIS 或纸质处方，康复师只在训练前核对本次运动项目与计划次数。

## 核心闭环

`OCR 导入患者资料 → 人工核对 → 患者到诊 → 对照外部处方选择项目 → 训练前评估 → 设备连接 → 视频训练 → 训练后评估 → 自动生成单次报告 → 医生选择训练记录生成阶段报告 → 医生确认 → 出院报告/康复手册 → 随访提醒`

明确不做：

- 系统内正式开具或调整运动处方
- AI 生成处方、自动诊断或自动调方
- 医生在本系统维护完整病历和医嘱
- 患者注册、自助建档或填写随访问卷
- 预约管理和 AI 外呼
- 患者签署临床报告

## 医护 Web 端

业务菜单：

- 今日工作台：报告待办、随访待办、今日到诊与训练概览
- 训练工作台：患者到诊、项目核对、训练前评估、设备检查、训练执行、训练后评估与单次报告
- 阶段与出院报告：医生勾选具体训练记录生成阶段报告；确认后形成出院报告/康复手册
- 随访管理：出院报告发布后生成提醒，支持短信/在线提醒展示、人工电话记录和高风险升级
- 患者数据：单张 OCR、历史批量 OCR、手工补录基础资料、人工核对、评估/训练/报告追溯

体能评估是患者数据详情的子页面，不作为侧边栏一级菜单。

后台仅保留：

- 视频资源
- 组织权限
- 报告打印签名

权限边界：

- 医生确认阶段报告和出院报告，并使用本人签名
- 康复执行岗记录训练事实、录入评估和人工随访，不能修改诊断、风险等级或正式处方参数
- 管理员配置账号、权限和签名模板，但没有临床签署权限
- 患者只能查看本人已发布的内容

## 患者训练 Pad

- 首页保持训练、日历、报告、个人四个一级入口
- 今日运动项目由康复师对照医院正式处方选择
- 右侧显示累计完成次数和“我的康复手册”
- 功率车训练使用沉浸式视频，悬浮显示运动时间、剩余时间、阶段进度和独立心率区域
- 底部展示速度、距离、功率、阻力、热量、血氧和间歇血压测量点
- RPE 由患者或康复师主动选择，不设置默认值
- 训练完成后可查看单次报告
- 不显示 AI 内部草稿、医生内部意见、处方编辑或患者自填随访入口

## 报告口径

单次报告来自一次实际训练，区分训练前、训练中和训练后指标；血压只展示带时间的间歇测量点，不模拟连续曲线。

阶段报告默认预选最近 4 次已完成训练，也可由医生勾选其他记录。报告保存实际的训练记录 ID，汇总数量与预览卡片严格一致。AI 仅生成阶段摘要草稿，医生确认后才形成正式结论。

出院报告发布后，患者端才能查看康复手册并生成后续随访提醒。网页预览可使用轻量动画，PDF 保持静态、可打印的医疗文书样式。

## 安全声明

- 仅使用本地 Mock、模拟或脱敏数据，不接真实患者和真实设备。
- OCR、HIS、短信、数字签名和设备接口均为交互演示。
- 缺失字段显示“未采集”，不按 0 参与均值或趋势结论。
- 演示阈值不等同于临床标准。
- 所有临床结论必须由医生确认，本系统不提供自动诊断、自动处方或自动设备控制。
