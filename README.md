# 心康伴侣——双系统需求调研 Demo V2.1

> 这是独立的 V2.1 功能重构目录。V2 位于 `../心康伴侣-医生调研Demo-v2`，本版不覆盖 V2 或原版，可随时回退。

冠心病Ⅱ期院内康复多模态 AI 辅助平台的本地前端演示原型。项目明确拆分为两个独立使用端：

- 医护 Web 端：医生根据报告生成、复核、签署和打印处方；护士在独立工作区查看院内任务、设备与训练状态。
- 患者训练端：以一期 Android 功率车闭环为功能基线，适配 iPad 横屏演示，覆盖身份证登录、首次建档、运动首页、处方确认、双设备检查、心理准备、血压模式、视频训练和训练结果。

对应的页面级功能说明、流程、规则和医生调研问题见：

- [`docs/PRD-心康伴侣-双系统调研演示版-V1.1.md`](./docs/PRD-心康伴侣-双系统调研演示版-V1.1.md)
- [`docs/医生调研功能讲解提纲-V1.1.md`](./docs/医生调研功能讲解提纲-V1.1.md)

## 技术栈

- React 18
- Vite 6
- TypeScript
- Tailwind CSS
- Lucide React

## 本地启动

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址（默认 `http://127.0.0.1:4182`）。

## V2.1 患者端功能更新

- 新增身份证号登录及首次登录建档；演示数据全部脱敏。
- 首页新增功率车、椭圆机、抗阻训练入口、打卡日历和个人档案。
- 训练首页按五大运动类型组织：呼吸训练、有氧运动、抗阻运动、柔韧性运动和中医运动；各类型下可选择具体项目。
- 登录后的 Pad 框架使用固定左侧图标导航，包含训练、日历、报告、个人四个一级栏目。
- 新增患者训练报告页，展示月度完成情况、医生反馈与历史训练记录。
- 报告页分为“单次报告”和“阶段性报告”两个 Sheet；单次报告先展示训练记录列表，点击记录后进入患者与处方字段、执行时间饼图、分期指标及生命体征/心电趋势详情。
- 阶段性报告按V1–V4四个处方版本汇总，展示调方原因、FITT参数、执行剂量、靶区达标、安全事件、功能变化、患者感受及医生确认后的下一阶段建议。
- 功率车处方可演示选择目标心率、连续/间歇、热身、主要训练、放松和循环次数。
- 背包与功率车分别检查，两个设备均通过后才可继续。
- 新增训练前心理准备评估与血压测量模式选择。
- 训练页使用一期骑行视频，并展示热身/训练/放松阶段、心率、速度、距离、功率、阻力、热量、血氧、血压和 RPE。
- 医生 Web 端保持 V2 实现不变。

生产构建检查：

```bash
npm run build
npm run preview
```

## 推荐演示路径

### 医生 Web

双系统入口 → 医护 Web 端 → 医生处方工作台/报告中心/患者档案，或进入同一 Web 内的院内护士站。

### 患者训练端

双系统入口 → 患者训练端 → 身份证登录（或首次建档）→ 首页 → 护士确认功率车 → 处方确认 → 背包与功率车连接 → 心理准备 → 血压模式 → 视频训练 → 训练结果。

患者端优先按 `1024×768` 横屏尺寸设计，同时兼容更宽的横屏平板和投影环境。

## 安全声明

- 仅使用本地 Mock、模拟或脱敏数据。
- 不接真实患者、HIS / EMR、数据库或真实设备。
- AI 只生成草稿，必须经医生审核。
- 演示异常规则不是临床阈值。
- 患者端处方调整仅用于医护调研演示；真实患者权限只应查看和确认。
- 不支持 AI 自动诊断、自动发布处方、自动控制设备或异常后自动恢复。
