# PRD V2.1 与业务会议需求合并基线

## 1. 采用原则

本 Demo 以《PRD-心康伴侣-图文功能需求评审版-V2.1》为产品骨架，以业务组会议的最终结论修正落地口径。旧 PRD 与会议冲突时，采用已确认的会议结论；技术组已经实现且仍符合安全边界的处方、异常与预约能力继续保留。

## 2. 当前产品闭环

患者资料导入与核对 → 医生处方辅助草稿与人工复核 → 预约到诊 → 康复师训练前评估 → 设备连接 → 患者训练 → 异常现场处置与医生复核 → 单次报告 → 康复师选择实际训练生成阶段报告 → 康复报告/手册发送 → 人工电话随访。

## 3. 角色边界

- 管理员：组织权限、视频、打印签名模板、异常规则；临床业务只读，不得代签。
- 医生：团队患者可见；仅编辑和签署本人处方任务；复核康复师提交的异常事件；训练大屏只读。
- 康复师：患者资料、评估、治疗与训练事实记录；异常现场处置；预约；阶段报告、康复报告和人工电话随访。
- 患者：仅查看本人已发布内容并执行训练，不建档、不编辑处方、不填写随访问卷。

## 4. 处方模块口径

- 处方只做 Demo，不接真实医嘱服务。
- 状态：待生成 → 待复核 → 待签署 → 已完成。
- 必须展示上一版、AI建议、医生最终值三值对比。
- AI只生成草稿，不自动诊断、调方、签署或发布。
- 只有责任医生可编辑、确认和签署；其他医生、康复师和管理员只读或不可见。
- 患者端只读取已经签署发布的内容；草稿和内部复核语永不下发。

## 5. 异常模块口径

- 设备数据或主诉触发异常快照。
- 康复师负责暂停/终止、复测和现场处置事实记录。
- 医生仅在现场记录提交后形成复核结论并闭环。
- AI解读属于辅助信息，不能替代临床判断。
- 页面阈值全部标记为 Demo，不得当作医院临床标准。
- 血压按测量时间展示离散测量点，不模拟连续曲线。

## 6. 预约模块口径

- 康复师创建、编辑、完成或取消预约。
- 医生查看本人患者的到诊安排；管理员只读。
- 预约记录患者、运动项目、工位、责任医生与备注。
- 同一患者或工位在同一时间不能重复预约。

## 7. 会议结论继续保留

- 患者不能自助建档；资料由医护端导入或补录。
- 体能评估支持同一患者批量 OCR、单张 OCR 和手工填写。
- 心肺康复治疗记录按纸表字段录入、签名与 A4 打印。
- 拿不到可靠处方计划次数时，不展示“11/36”、剩余次数和处方完成率。
- 阶段报告由康复师发起，保存实际纳入的训练记录 ID，不要求医生逐次点击生成。
- 不同运动项目不混算功率、速度或目标心率。
- 患者随访由康复师人工电话记录，患者端不填写表单。
- 全部医院、患者和编号信息必须脱敏。

## 8. 当前 Demo 不做

- 真实 HIS/EMR、OCR、设备、短信、药品字典或数字签名服务。
- 自动诊断、自动处方、自动调方或 AI 外呼。
- 患者自助建档、患者随访表单、患者临床报告签署。
- 完整院级后台治理和复杂跨院区组织模型。
