## 1. 整体产品形态

当前前端由两个系统组成：

1. **医护 Web 工作站**
   - 面向管理员、康复医生、康复执行岗。
   - 典型 B 端后台风格：左侧固定导航 + 顶部状态栏 + 内容卡片区。
   - 字号偏小、密度偏高、强调表格、状态、复核、签署、审计。

2. **患者 Pad 训练端**
   - 面向患者或护士协助患者使用。
   - iPad / Android 横屏体验。
   - 大按钮、大圆角、清晰流程、沉浸式训练视频、语音/安全提示。

复现时不要把两套端混成一种视觉。医生端要“专业、克制、信息密度高”；患者端要“温和、清楚、触控友好”。

## 2. 全局视觉语言

### 2.1 字体

统一使用：

```css
font-family: Inter, "PingFang SC", "Microsoft YaHei", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

设计规则：

- 医生端正文：11–12px 为主。
- 医生端卡片标题：14px。
- 医生端页面标题：22px 左右。
- 患者端正文：12–14px 为主。
- 患者端重要数字/训练时间：24–48px。
- 不使用宋体，不使用过多装饰字体。

### 2.2 主色

当前基础主色是医疗青绿，但医生端进行了蓝色化处理。

| 用途 | 推荐颜色 |
|---|---|
| 全局患者端主色 | `#1f7e79` |
| 患者端深色标题 | `#17324d` |
| 患者端浅背景 | `#edf3f5`, `#eef7f6`, `#f8fbfb` |
| 医生端主按钮蓝 | `#3f7cff` |
| 医生端高亮蓝 | `#3476f6` |
| 医生端浅蓝背景 | `#eef4ff`, `#f5f8ff` |
| 成功 | `#10b981` / emerald |
| 警告 | `#f59e0b` / amber |
| 危险 | `#ef4444` / red |
| 灰边框 | `#dbe6ec`, `#e5eaf2`, `#e8edf4` |

颜色使用规则：

- 医生端主色优先用蓝色，不要大面积使用深绿。
- 患者端主色优先用青绿，整体更柔和。
- 风险状态不能只靠颜色，要加文字：如“高危”“待复核”“声音警报”。
- 红色只用于异常、危险、停止训练、删除等高风险行为。

### 2.3 背景与卡片

#### 医生端背景

```css
background:
  radial-gradient(circle at 78% 0%, rgba(87, 139, 255, 0.08), transparent 24rem),
  #f3f6fb;
```

复现要点：

- 页面底色是很浅的蓝灰，不是纯白。
- 内容用白色卡片承载。
- 卡片圆角约 12px。
- 卡片边框 `#e5eaf2`。
- 阴影很轻：`0 6px 22px rgba(52, 83, 129, 0.045)`。

#### 患者端背景

```css
background:
  radial-gradient(circle at 12% 8%, rgba(31, 142, 135, 0.12), transparent 28rem),
  linear-gradient(145deg, #eef7f6 0%, #f8fbfb 52%, #edf4f7 100%);
```

复现要点：

- 页面更像 Pad 应用，不像传统后台。
- 大圆角卡片：24–32px。
- 白色卡片带柔和阴影。
- 交互按钮最小高度 52px，方便触控。

### 2.4 圆角和阴影

| 组件 | 圆角 | 阴影 |
|---|---:|---|
| 医生端普通卡片 | 12px | 很轻 |
| 医生端按钮 | 8–10px | 主按钮轻蓝色阴影 |
| 患者端卡片 | 24–32px | `shadow-card` |
| 患者端训练视频容器 | 24–32px | 较强悬浮感 |
| 状态标签 | pill / 999px | 无或极轻 |

## 3. 通用组件复现规则

### 3.1 PageHeader 页面头

每个医生端主页面顶部统一为：

- 上方小字 eyebrow：蓝色、大写或短标签，9–10px。
- 主标题：22px、深色、粗体。
- 描述：11–12px、灰色、最多 2 行。
- 右侧可放状态标签、刷新按钮、新增按钮。

复现模板：

```text
[eyebrow 小标签]
页面主标题                         [右侧操作/状态]
页面说明文案
```

### 3.2 SectionHeader 区块标题

卡片内部区块统一为：

- 标题 14px 粗体。
- 描述 11px 灰色。
- 右侧可以放状态、按钮。

不要让每个卡片标题风格各自发挥。

### 3.3 Card 卡片

医生端卡片：

```text
白底 + 12px 圆角 + 1px 浅边框 + 轻阴影 + 16–20px 内边距
```

患者端卡片：

```text
白底 / 浅色底 + 24–32px 圆角 + 大留白 + 大按钮
```

### 3.4 状态标签 StatusBadge

统一为小胶囊：

| 状态 | 颜色 |
|---|---|
| 已完成、已发布、已复核 | 绿色 |
| 待复核、待发布、改期 | 橙色 |
| 异常、高危、警报 | 红色 |
| 处理中、AI 草稿、单次报告 | 蓝色 |
| 只读、草稿、无数据 | 灰色 |

标签要写清楚业务含义，例如不要只写“正常”，要写“医生已复核”“已发布”“待签名”。

### 3.5 表格

当前表格大多不是标准 table，而是 CSS grid 风格列表。

复现规则：

- 表头背景：`#f8fafc` 或浅灰。
- 表头文字：10px、灰色、粗体。
- 行高：42–54px。
- 行之间 1px 浅灰分隔。
- 可点击行 hover 使用浅蓝底。
- 长编号用等宽字体，字号 10px。
- 操作列用蓝色粗体文字 + 小箭头图标。

### 3.6 表单

字段统一：

- label：11px 左右，灰色/深灰，半粗体。
- 输入框：白底、10px 圆角、浅灰边框、内边距 12px。
- 医生端输入框高度约 34–40px。
- 患者端输入框高度可以更高。
- 禁用态：浅灰底，文字不完全隐藏。

### 3.7 按钮

| 类型 | 使用场景 | 视觉 |
|---|---|---|
| 主按钮 | 保存、确认、签署、提交、进入下一步 | 蓝色/青绿色底 + 白字 |
| 次按钮 | 返回、重置、打印预览、查看 | 白底 + 浅灰边框 |
| 危险按钮 | 停止训练、删除、异常处理 | 红色底或红色浅底 |
| 幽灵按钮 | 标签切换、局部状态切换 | 浅灰底，激活变白/蓝 |

高风险按钮必须有清楚文字，不要只放图标。

## 5. 医护 Web 端逐页设计规则

### 5.1 系统入口页

页面定位：双系统入口，选择进入医护端或患者端。

布局：

- 全屏浅灰绿背景。
- 顶部品牌栏：左侧 Logo 和平台名，右侧“需求调研 Demo · 模拟/脱敏数据”标签。
- 中部大标题：两行大字，“让每一次心脏康复训练，更安全、更清晰。”
- 下方两个大卡片：
  - 左侧深色渐变卡：医护业务与管理后台。
  - 右侧白色卡：患者训练端。

复现规则：

- 左卡要明显更重，用深青蓝渐变。
- 右卡要轻，用白底和浅边框。
- 两张卡高度保持一致，约 330px。
- 卡片内部都有图标、角标、标题、说明、能力标签和右箭头。

### 5.2 医护登录页

页面定位：医护 Web 身份认证与角色预览。

布局：

```text
居中大容器，左右双栏
左栏：蓝色渐变品牌说明
右栏：登录表单 + 角色卡片 + 权限预览
```

左栏内容：

- 返回系统入口。
- 心康伴侣 Logo。
- 大标题：“一个入口，按岗位进入各自的工作边界。”
- 3 条能力：角色权限、数据隔离、签署审计。

右栏内容：

- 标题：登录医护工作站。
- 3 个角色卡片：系统管理员、康复医生、康复执行岗。
- 账号、密码输入框。
- 权限预览蓝色卡片。
- 主按钮：以某角色身份登录。

复现规则：

- 角色卡片用三列。
- 选中角色：蓝边框 + 浅蓝底 + 外圈浅蓝 ring。
- 错误提示用红色浅底卡。
- 演示密码文案要保留：`123456`。

### 5.3 今日工作台：医生/管理员

页面定位：医生每天进入后的工作总览，不是医院运营大屏。

布局：

- 顶部 PageHeader。
- 第一行 5 个指标卡：
  - 总患者数
  - 总运动处方量
  - 待开具处方数
  - 平均训练完成率
  - 训练异常记录数
- 医生视图下方：
  - 今日预约患者卡
  - 处方/报告任务排行卡
  - 趋势卡
  - 随访提醒卡
  - 待复核处方卡
- 管理员视图下方：
  - 趋势卡
  - 任务排行
  - 提醒列表
  - 今日预约患者

复现规则：

- 指标卡每张独立白卡，图标在左上，数字大，备注小。
- “待开具处方数”可点击，橙色强调。
- 异常类指标用红色但不要满屏红。
- 医生工作台重点放“要做什么”，不要放无关流程图。

### 5.4 今日工作台：康复执行岗

页面定位：康复师/护士看今天训练执行，不负责开处方。

布局：

- 顶部 PageHeader：“周康复师，上午好”。
- 第一行 5 个执行指标：
  - 今日训练计划
  - 待接诊
  - 在训患者
  - 训练后确认
  - 异常待上报
- 下方两列：
  - 左：下一步执行任务列表。
  - 右：执行权限边界。

复现规则：

- 任务列表按时间排序，左侧时间用等宽小字。
- 权限边界用“可做/不可做”的图标区分。
- 明确写出：康复执行岗不能复核或签署临床处方。

### 5.5 预约患者处方闭环详情

入口：医生工作台点击今日预约患者。

布局：

```text
三列布局：
左：患者与报告入口
中：报告摘要
右：AI 运动参数建议 / 处方草稿
```

左列：

- 患者姓名、患者号、阶段、风险。
- 阶段性报告 / 单次报告切换。
- 报告 ID 列表。

中列：

- 如果选择阶段报告：展示医生摘要、完成次数、靶区、异常、安全事件。
- 如果选择单次报告：展示运动项目、平均心率、靶区时间、血压、血氧、心电。

右列：

- 运动项目、频次、热身/训练/放松、靶心率、功率/阻力、RPE、饮食与注意事项。
- 上一版处方摘要。
- 按状态显示：生成 AI 草稿、医生确认参数、数字签名、打印最终报告。

复现规则：

- 这是闭环页，不能只做摘要卡。
- 三列宽度大致为 `0.7fr / 1.05fr / 0.85fr`。
- AI 内容必须表现为“建议/草稿”，不能像最终医嘱。

### 5.6 处方管理

页面定位：处方任务总表。

布局：

- PageHeader：管理员叫“运动处方总台”，医生叫“我的运动处方”。
- 顶部右侧状态：未完成 X · 已完成 Y。
- 筛选区：患者号、处方号、所属医生、状态、查询、重置。
- 下方大表格：患者姓名、患者号、处方号、版本、阶段、分组、类型、依据、生成时间、所属医生、状态、操作。

复现规则：

- 医生登录时所属医生字段只读，显示“仅本人”。
- 管理员可以筛选全部医生。
- 已完成处方操作叫“查看/打印”。
- 待生成处方操作叫“AI 生成处方草稿”。
- 待复核/待签名叫“编辑审核”。

### 5.7 处方工作站

入口：处方管理或工作台点击某一条处方任务。

页面定位：医生完整复核、编辑、签署处方的主页面。

布局：

- 顶部处方详情 hero，显示患者、处方号、状态、返回。
- 中间左侧竖向步骤导航：
  1. 患者资料
  2. 问诊记录
  3. 本次处方
  4. 历史处方
  5. 报告依据
- 右侧为当前步骤内容。
- 底部固定操作条：
  - 上一步
  - 保存草稿
  - 下一步 / 确认并签署

各 tab 复现要点：

#### 患者资料

- 身份主索引只读。
- 临床资料可编辑：危险分组、特殊用药、诊断摘要、既往史。
- 康复评估区展示 SPPB、6MWT、CPET 和状态。

#### 问诊记录

- 左右结构：本次问诊填写 + 历次口述列表。
- 只记录影响开方的主诉、用药依从性、训练反馈、生活方式和新增事件。

#### 本次处方

- 上方 AI 工作区，展示生成依据、缺失数据、草稿状态。
- 下方运动处方编辑区，包含康复目标、呼吸训练、有氧训练、抗阻训练、柔韧训练、中医运动、注意事项。
- 签署前必须看到阻断项：资料缺失、风险未复核、内容未确认等。

#### 历史处方

- 展示上一版处方参数和医生建议。
- 提供“从上一版逐项沿用”入口。
- 医生需要勾选/确认“已查看上一版依据”。

#### 报告依据

- 单次报告/阶段报告切换。
- 显示训练执行、实际心率、血压、血氧、异常事件。
- 报告是开方依据，不是装饰。

复现规则：

- 处方工作站要像一个流程工作台，不要做成普通详情页。
- 竖向步骤导航必须保留步骤编号和状态文字。
- 底部固定操作条是关键，不要漏。

### 5.8 患者档案

页面定位：统一患者主数据与康复链路。

列表页布局：

- PageHeader：患者信息与康复档案。
- 右侧有“新增患者”按钮。
- 筛选：关键词、风险、阶段等。
- 患者列表使用卡片/表格混合：患者姓名、患者号、诊断、风险、主管医生、训练状态、报告状态、随访。

详情页布局：

- PageHeader：`患者姓名 · 患者编码`。
- 顶部 tab：
  1. 档案概览
  2. 体能评估
  3. 口述记录
  4. 随访计划
  5. 历次处方
  6. 训练记录
  7. 患者报告
- 每个 tab 下都是白色卡片。

复现规则：

- 患者详情必须能串起“档案 → 评估 → 处方 → 训练 → 阶段报告 → 随访 → 下一阶段处方”。
- “新增患者”是医生工作台/患者档案的核心入口。
- 患者档案不是处方页的替代品，处方任务仍回到处方工作站。

### 5.9 评估采集

页面定位：基于纸质 SPPB 评估表的结构化采集。

布局：

```text
左列：患者与历史评估
右侧：当前评估表单
```

左列：

- 患者选择。
- 新建 SPPB 评估按钮。
- 历史评估卡片：第几次、日期、总分、状态。

右侧：

- 未选择患者时显示空状态。
- 选择/新建后显示：
  - 原始表与来源
  - OCR 演示结果
  - 测试信息
  - 测试前后血压/脉搏
  - SPPB 原始测试值：平衡、4 米步行、椅子坐立
  - 系统计算总分
  - 康复师确认 / 医生复核按钮

复现规则：

- 原始值和计算分数要分开。
- OCR 只是辅助入口，要显示“人工核对”。
- 管理员只读，康复执行岗采集确认，医生复核。

### 5.10 随访管理

页面定位：出院后 1、3、6 个月随访任务闭环。

布局：

- PageHeader：院后康复管理。
- 顶部状态/视图切换：待随访、逾期、已完成。
- 列表页展示：患者、节点、到期日期、状态、主管医生、最近联系。
- 详情/表单页展示：
  - 任务信息
  - 患者端自报
  - 本次沟通结果
  - 症状与事件
  - 依从性与训练执行
  - 再次联系安排
  - AI 摘要草稿
  - 改期记录

复现规则：

- 联系失败不算完成，要进入“再次联系安排”。
- 高风险症状要升级医生复核。
- AI 摘要必须是“草稿”，并需要人工确认。
- 管理员只读，不能代医生提交。

### 5.11 康复报告

页面定位：康复出院报告，不是单次/阶段训练报告。

布局：

- PageHeader：康复出院报告。
- 顶部患者选择条，显示数据来源数量和随访节点数量。
- 三列主体：
  1. 医生治疗部分
  2. 系统康复部分
  3. 后续建议草稿
- 下方发布检查。
- 底部按钮：打印预览、保存草稿、确认报告、发布给患者。

复现规则：

- 医生治疗部分为蓝色浅底。
- 系统康复部分为绿色浅底。
- 后续建议草稿为紫色浅底。
- 发布给患者前要通过检查：治疗部分完整、康复数据有来源、医生已确认。
- 患者端只能看到已发布报告。

### 5.12 训练工作台

页面定位：康复执行岗看现场训练，医生看概览。

布局：

- PageHeader：训练工作台。
- 顶部指标卡：今日任务、待接诊、在训、设备、异常等。
- 左侧今日训练任务列表。
- 右侧或下方异常上报闭环和现场处置记录。

复现规则：

- 训练工作台不是医生监控大屏，不要做复杂流程图。
- 医生看到的是观察视图，非本人任务要匿名/简化。
- 康复执行岗可以记录现场事实，但不能形成处方或医学结论。

### 5.13 视频资源

页面定位：后台资源管理，不是患者播放页。

当前版本规则：

- 只采用本地视频文件。
- 不再支持外部链接和嵌入播放器。
- 医生/康复执行岗可以维护草稿。
- 管理员负责发布、下架、删除/恢复等。

布局：

```text
左列：添加训练视频
右列：分类视频列表 + 预览
```

复现规则：

- 添加区要有：视频名称、运动大类、训练子类型、上传文件。
- 列表按运动大类筛选。
- 视频状态用标签：草稿、待发布、已发布、已下架、回收站。
- 预览区展示视频画面、运动大类、训练子类型、素材来源、最近维护。

### 5.14 组织权限

仅管理员可见。

页面定位：3 个月验证版最小组织与权限配置。

布局：

- PageHeader：组织权限。
- 顶部 tab/sheet：组织账号、权限配置。
- 组织账号页：
  - 组织边界
  - 账号与岗位列表
- 权限配置页：
  - 角色选择
  - 操作权限列表
  - 验证版权限口径说明

复现规则：

- 不要做成完整 HIS 组织架构后台。
- 只保留验证团队、角色和关键操作权限。
- 权限展示要强调：菜单可见不等于服务端授权。

### 5.15 报告打印签名

仅管理员可见。

页面定位：报告模板、处方打印、数字签名配置。

布局：

- PageHeader：报告打印签名。
- 卡片：模板与签名配置。
- 列表项包括：单次报告模板、阶段报告模板、处方打印模板、数字签名配置、签署记录。

复现规则：

- 页面要小而核心，不扩展消息通知、审计中心、接口配置等大后台能力。
- 强调签署和打印服务处方闭环。

## 6. 患者 Pad 端全局骨架

### 6.1 App 框架

患者端不是 Web 后台，而是横屏训练 Pad。

进入后通用骨架：

```text
左侧图标导航 72px 左右
右侧主内容
顶部患者信息 / 当前页面标题
功率车流程页显示流程条
```

左侧导航：

- 图标为主，文字很少。
- 入口包括：首页、日历、报告、个人。
- 当前项用主色高亮。

### 6.2 患者端导航和流程

首页选择运动项目：

- 呼吸训练：腹式呼吸、正念呼吸
- 有氧运动：功率车、椭圆机
- 抗阻运动：哑铃、弹力带
- 柔韧性运动：上肢拉伸、下肢拉伸、全身柔韧
- 中医运动：八段锦、太极拳

功率车流程：

```text
确认处方 → 设备检查 → 心理准备 → 血压模式 → 开始训练 → 训练结果
```

复现规则：

- 功率车是完整闭环。
- 非功率车如果有发布视频，进入视频跟练。
- 没发布视频时按钮不可用并提示联系医护。

## 7. 患者 Pad 端逐页设计规则

### 7.1 患者登录页

页面定位：身份证/患者号登录。

布局：

- 居中白色大卡片。
- 左侧或顶部品牌说明。
- 输入身份证号/患者号。
- 首次登录入口：创建档案。
- 返回系统入口按钮。

复现规则：

- 输入区要大，按钮要高。
- 说明文案用患者能懂的话，不出现医生端“权限/复核”等术语。

### 7.2 首次建档页

页面定位：患者首次登录补充基础信息。

布局：

- 全屏浅色背景。
- 白色表单卡。
- 字段包括：姓名、身份证、性别、年龄、联系方式、分组/既往处方相关信息。
- 底部保存并进入首页。

复现规则：

- 不要让患者填写复杂诊断和处方核心字段。
- 建档更多是演示入口，正式临床信息由医生/康复中心确认。

### 7.3 患者首页

页面定位：今日康复入口。

布局：

- 顶部显示患者问候、阶段、风险/处方摘要。
- 运动分类为大标题：
  - 呼吸训练
  - 有氧运动
  - 抗阻运动
  - 柔韧性运动
  - 中医运动
- 每个分类下方是可选子项目卡。
- 底部/右侧有主按钮：进入功率车训练或开始视频跟练。
- 如果有待随访任务，显示随访提醒入口。

复现规则：

- 分类标题要比子项目更醒目。
- 子项目卡片选中后变主色。
- 功率车显示“医生处方已审核 · 目标心率……”。
- 视频跟练显示“已发布视频：xxx”。

### 7.4 视频跟练页

适用于：呼吸、椭圆机、哑铃、弹力带、柔韧、中医等非功率车视频。

布局：

```text
左：大视频播放器
右：训练处方 / 注意事项 / 生理监测开关
```

视频区：

- 深色播放器背景。
- 顶部显示分类、子类型、视频标题、跟练计时、全屏按钮。
- 可选显示监测条：心率、血氧、心电提示。

右侧：

- 建议时长、目标强度、动作节奏、呼吸要求。
- 注意事项。
- 完成按钮。

复现规则：

- 默认不遮挡教学视频。
- 生理监测是可选开关，不要默认盖满画面。
- 计时是跟练计时，不一定等于设备真实运动剂量。

### 7.5 功率车处方确认页

页面定位：训练前让患者/护士核对本次医生处方。

布局：

- 两列布局。
- 左侧：处方核心参数。
- 右侧：医生写给患者的注意事项。

内容：

- 训练方式
- 热身/训练/放松时间
- 靶心率
- 功率/阻力
- RPE
- 饮食注意
- 运动注意
- 停止运动条件
- 用药提醒

复现规则：

- 患者端只能确认/查看，不能编辑处方。
- 文案要患者可读，不要出现“AI草稿”“医生内部复核”。

### 7.6 设备检查页

页面定位：训练前检查背包和功率车连接。

布局：

- 白色大卡片。
- 两张设备状态卡：
  - 心电背包/背包设备
  - 功率车
- 每张卡显示图标、连接状态、操作按钮。
- 底部：返回处方、重新检测、继续。

复现规则：

- 两个设备都通过后才能继续。
- 通过状态用绿色 check。
- 未通过状态用橙色/灰色，不能直接进入下一步。

### 7.7 心理准备页

页面定位：训练前心理/主观状态自评。

布局：

- 白色卡片。
- 题目列表，每题 2–4 个选项。
- 选项为大号 pill/卡片按钮。
- 底部返回与继续。

复现规则：

- 所有题目答完后才能继续。
- 这是训练前准备的一部分，必须在设备连接通过之后。

### 7.8 血压模式页

页面定位：选择训练中的血压测量模式。

布局：

- 三张大卡片横排：
  - 训练前后测量
  - 多次测量
  - 本次不测
- 选中态：主色边框 + 浅色背景 + “已选择”。
- 底部主按钮：开始功率车训练。

复现规则：

- 未选择模式前主按钮禁用。
- 血压是间歇测量，后续报告不能画成连续实时曲线。

### 7.9 功率车训练页

页面定位：核心沉浸式训练页面。

布局：

```text
顶部：运动时间 / 三阶段进度条 / 剩余时间
中部：大视频区域 + 右侧心率与指标区
视频底部悬浮：暂停、下一阶段/结束、演示异常
右侧：实时心率卡 + 指标小卡
```

顶部：

- 运动时间在左。
- 中间显示“热身 X 分钟 · 训练 X 分钟 · 放松 X 分钟”。
- 三阶段进度条按时间推进。
- 当前阶段标签：热身 / 主要训练 / 放松。
- 剩余时间在右。

视频区：

- 使用大视频，占主视觉。
- 当前 Demo 采用功率车沉浸式训练视频。
- 视频上可以悬浮按钮和异常遮罩。
- 暂停训练时显示白色暂停遮罩。

心率区：

- 单独一块“实时心率”卡。
- 大数字 bpm。
- 目标心率彩色区间条。
- 心率状态文字。
- 语音提示/声音警报文字。

指标区：

- 速度
- 距离
- 功率
- 阻力
- 血氧
- 血压
- 热量
- RPE

复现规则：

- 不要用黑底游戏风格，整体仍保持医疗浅色风格。
- 视频要放大，指标要服务沉浸感。
- 功率车页面里的“运动时间”和“剩余时间”必须悬浮/固定在训练界面上方。
- 异常演示时红色提醒要清楚，但不能遮掉全部操作。
- 语音播报文案要跟阶段同步，例如进入训练阶段播报“现在进入训练阶段，努力加油吧”。

### 7.10 训练结果页

页面定位：功率车完成后的结果确认。

布局：

- 左侧：完成状态、训练摘要、返回首页、查看单次报告。
- 右侧：训练指标、处方执行情况、安全提示。

复现规则：

- 必须有两个主要按钮：
  - 返回首页
  - 查看单次报告
- 查看单次报告应跳转到患者报告页对应单次报告。

### 7.11 患者随访自报页

页面定位：患者出院后随访前自填信息。

布局：

- 顶部标题：出院后 X 个月随访。
- 症状与近期事件卡。
- 依从性与生命体征卡。
- 提交按钮。

字段：

- 症状多选：胸闷、胸痛、心悸、气促、头晕、持续胸痛、晕厥等。
- 用药依从性。
- 运动依从性。
- 训练频率。
- 单次训练时长。
- 血压/心率手工填写。
- 遇到困难。
- 补充说明。

复现规则：

- 出现持续胸痛、晕厥，或备注里出现急诊/住院，应显示高风险提交提示。
- 患者提交后由医护人员确认，患者端不要显示后台处理细节。

### 7.12 患者报告页

页面定位：患者查看自己的训练报告和康复出院报告。

结构：

- 单次报告列表
- 阶段性报告
- 康复出院报告（如果医生已发布）

单次报告复现要点：

- 列表点击进入详情。
- 展示患者能理解的病史、诊断、特殊用药摘要。
- 核心指标为实际心率和实际血压。
- 血压显示测量时间点。
- 不出现医生端内部术语。

阶段报告复现要点：

- 医患共读风格。
- 先给阶段结论，再给 V1–V4 处方演变、完成率、靶区达标、安全事件、能力变化。
- 缺失数据写“未采集”，不要写 0。

康复出院报告复现要点：

- 医生治疗部分。
- 康复数据。
- 居家康复与后续建议。
- 显示“医生已确认/已发布”。

### 7.13 个人档案页

页面定位：患者查看个人信息。

布局：

- 白色卡片列表。
- 展示：姓名、患者号、性别年龄、分组、阶段、风险、当前处方摘要、医生建议。

复现规则：

- 患者端是查看为主。
- 不提供诊断、用药、处方核心字段编辑能力。

### 7.14 打卡日历页

页面定位：查看训练打卡。

布局：

- 月历或卡片式日历。
- 已完成日期用绿色/主色标记。
- 未完成或异常日期用橙色/红色标记。
- 下方展示近期训练摘要。

复现规则：

- 日历是患者自我管理入口，不要做医生端统计大屏。

## 8. 响应式与尺寸规则

### 医护 Web

- 设计基准：桌面 Web，宽度 1366–1540px。
- 左侧导航固定 180px。
- 主内容最大宽度 1540px。
- 表格允许横向滚动。
- 1024px 下优先保留 PageHeader、筛选、核心表格；复杂三列可以改两列或纵向堆叠。

### 患者 Pad

- 设计基准：横屏 1024×768 或更大。
- 触控按钮高度 ≥ 52px。
- 功率车训练页优先保证：
  1. 视频可见
  2. 运动时间/剩余时间可见
  3. 当前阶段可见
  4. 心率卡可见
  5. 停止/暂停按钮可见

## 9. 页面复现时的禁止项

1. 不要把医生端做成患者端大按钮风格。
2. 不要把患者端做成医生端表格后台。
3. 不要在患者端出现“AI 草稿”“医生复核”“权限配置”等内部词。
4. 不要暗示 AI 自动诊断、自动开方、自动发布处方。
5. 不要让康复执行岗能签署处方。
6. 不要让管理员冒用医生签名；管理员签署也必须显示本人身份。
7. 血压不要画成连续实时曲线，只能作为测量点。
8. 不要用大面积黑底管理大屏风格替代当前浅色医疗风格。
9. 不要增加复杂 HIS 后台菜单，当前是 3 个月验证 Demo。
10. 不要为了好看删除业务闭环：报告、处方、训练、随访之间必须能追溯。

## 10. 给同学的最低复现清单

如果时间有限，至少复现以下页面和规则：

1. 系统入口页：双入口卡片。
2. 医护登录页：三角色登录和权限预览。
3. 医护全局框架：左侧 180px 导航 + 顶部状态栏。
4. 今日工作台：医生任务导向 + 康复执行岗执行导向。
5. 处方管理：筛选 + 大表格 + 状态操作。
6. 处方工作站：五步 tab + 底部固定操作条。
7. 患者档案：列表 + 七 tab 详情。
