# V2.1 功能实现与回退说明

## 版本关系

- 原版：`../心康伴侣-医生调研Demo`
- V2 视觉版：`../心康伴侣-医生调研Demo-v2`
- V2.1 功能重构版：`../心康伴侣-医生调研Demo-v2.1`
- V2 设计原型：`../心康伴侣-医生调研Demo-design-v2`

四个目录相互独立。V2.1 不覆盖任何旧版源码、依赖或构建产物。

## 本轮差距修复

| 用户要求 / 一期功能基线 | V2 状态 | V2.1 实现 |
|---|---|---|
| 患者登录、首次建档 | 缺失 | 身份证号演示登录、首次建档、上次处方结构化摘要 |
| 今日运动、日历、个人中心 | 缺失 | 功率车/椭圆机/抗阻入口、周打卡、月日历、个人档案 |
| Pad 一级导航与报告 | 缺失 | 固定左侧图标导航；训练、日历、报告、个人独立内容区 |
| 四处方阶段报告 | 仅月度摘要 | V1–V4处方演变、执行剂量、安全事件、功能评估、患者反馈和下一阶段临床建议 |
| 功率车处方参数 | 仅静态展示 | 目标心率、训练类型、热身/训练/放松、循环次数可选 |
| 背包与功率车连接门槛 | 单一确认卡 | 两设备独立状态，均通过后解锁下一步 |
| 心理测试 | 缺失；一期也无该模块 | 新增 3 项训练准备度评估 |
| 血压模式 | 缺失 | 不测、前后两次、分阶段测量 |
| 视频训练与一期指标 | 缺失 | 一期视频、阶段卡、心率/速度/距离/功率/阻力/热量/血氧/血压/RPE |
| 训练结果 | 简化 | 增加计划完成、目标区间、距离、血压、功率、血氧和 RPE |
| 医护身份登录 | 无角色鉴权 | 管理员、医生、康复执行岗预设账号与权限预览 |
| 医护菜单权限 | 所有人看到同一菜单 | 业务工作与后台管理分组按角色显示 |
| 数据与字段权限 | 无 | 团队、康复中心、全部数据范围；临床核心字段锁定 |
| 随访管理 | 缺失 | 规则生成、共享队列认领、完成记录与异常升级 |
| 视频内容治理 | 已发布/未发布 | 草稿、待发布、已发布、已下架、回收站和动作授权 |
| 后台管理 | 仅运营概览 | 组织账号、权限、视频、业务、设备、文书、通知、审计与接口 |

椭圆机和抗阻训练本版先完成首页入口与状态说明，尚未接入设备和完整训练流程。真实设备协议也未在前端 Demo 中实现，当前连接与指标均为模拟状态。

## 启动

```bash
cd Codex/心康伴侣-医生调研Demo-v2.1
npm run dev
```

医护 Web 演示账号统一使用密码 `123456`：

- 管理员：`admin`
- 康复医生：`doctor.wang`
- 康复执行岗：`rehab.zhou`

## 回退

如本版功能或样式不合适，直接停止 V2.1 服务并启动 V2：

```bash
cd Codex/心康伴侣-医生调研Demo-v2
npm run dev
```

不需要执行 Git 回滚、覆盖文件或迁移数据。
